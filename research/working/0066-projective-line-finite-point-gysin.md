# Every finite P¹ point and affine-coordinate-independent Gysin (2026-11-26)

For every complex number a and unit u in ℂ, the normal coordinate is the actual
scheme map induced by X ↦ uX+a, followed by the original first affine chart
of the original glued P¹. The native point support is the original singleton
{finite a}. The supported and absolute Gysin maps are constructed from the
original local Thom class, these actual normal charts, original relative
excision and support forgetting. Both maps are independent of u.

`Topology/OnePointHomotopy.lean` proves joint continuity of compact-parameter
families on one-point compactifications with Hausdorff source, from jointly
continuous forward and left-inverse maps. A compact target complement has all parameterized preimages
contained in a compact image of the inverse family. The result uses no metric,
norm estimate or local-compactness hypothesis. This leaf uses only Mathlib.

`Geometry/ProjectiveLineAffineChart.lean` constructs the original polynomial
algebra automorphism and its actual affine Spec isomorphism, preserving the
base structure. Its composite with the original X chart is an open immersion
with the same scheme-point range. Actual evaluation sections prove the finite
formula a+u*z and identify their closed scheme center. The center is not the
generic point. This proves actual local algebraic chart data; no global scheme
affine automorphism of the glued projective line is asserted.

`Realization/Betti/Examples/ProjectiveLineAffine.lean` extends the actual complex
affine homeomorphism through the existing native one-point compactification
homeomorphism of the original point space. It fixes infinity and sends finite z
to finite(a+u*z). The coefficient exp(t*log(u)) is nonzero and joins one to u.
With translation t*a this gives an actual homotopy from identity to the affine
map, including at infinity. Joint inverse continuity and the compact-family
lemma prove its continuity. Original singular pullback is therefore identity
in every degree. The logarithm is chosen for each fixed unit; this does not
assert joint continuity of the homotopy in u across a logarithm branch.

`Realization/Betti/Examples/ProjectiveLineFinitePointSupport.lean` retains the
actual singleton, open complement, point H⁰ and constant unit. The actual affine

`Realization/Betti/ProjectiveLineFinitePointGysin.lean` defines its normal chart
point by composing actual scheme evaluation sections with the actual scheme
chart. The pointwise affine formula identifies this same map with its native
normal-coordinate homeomorphism. Original restriction and relative excision
therefore commute with actual affine transport. The local Thom class maps to
the original positive absolute generator because the actual affine map is
homotopic to identity. Native H⁰ of the singleton is generated by its constant
unit, so absolute Gysin is independent of the unit u. Faithful original support
forgetting upgrades that equality to the supported maps and supported Thom
classes themselves. No cycle-class coordinate defines these native maps.

`Realization/Chow/ProjectiveLineFinitePoint.lean` defines the original reduced
point representative and original ordinary rational Chow class at the actual
scheme evaluation center. The structural dimension function and quotient are
retained. The existing degree map gives degree one and nonvanishing over the

actual scheme image of the native singleton and proves that its ordinary cycle
