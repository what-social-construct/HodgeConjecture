## Checkpoint

For a field `k` and finite label sets, the existing cycle groups are freely
generated by actual integral ideal-sheaf subschemes of `Z_I = Spec(k^I)`.
The existing Chow groups are their quotients by principal-divisor relations,
proved zero. This step constructs their geometric operations before deriving
the matrix law for correspondences.

The geometric facts are:

1. The scheme-theoretic image of a point under `Z_f : Z_S → Z_I` is the
   actual point labelled `f(s)`. The induced map to that image is an
   isomorphism respecting its inclusion.
2. `Z_(I×J) ≅ Z_I ×_k Z_J`, with both projections respected. Its point
   inclusion labelled `(i,j)` is the actual product-point inclusion.
3. `Z_{s : f(s)=i} ≅ Z_S ×_{Z_I} s_i`, with the inverse-image inclusion
   respected. The ideal-sheaf inverse-image equality is proved as well.
4. Actual point stalks are isomorphic to `k`. The actual residue-field map
   of an isomorphism has degree one. The local ring of a fiber point has
   module length one over the ambient stalk through the actual stalk map.

The fourth item records the precise coefficients in the proper-pushforward
and fundamental-cycle definitions. It is stronger than merely calculating
the length of `k` over itself in unrelated coordinates.

## Cycle operations

For coefficient ring `R`, proper pushforward maps each actual integral
subscheme generator to its actual image. On point generators it is

```text
f_*[s] = [f(s)].
```

The actual restricted scheme map is an isomorphism, so the degree in this
formula is one. Linearity then gives summation over each fiber:

```text
(f_* z)_i = ∑_{s : f(s)=i} z_s.
```

`imageDegree` is defined using the actual residue-field map of the actual
image restriction. `pushforward_single_eq_imageDegree` identifies the
implemented pushforward with this degree-weighted formula.

Flat pullback copies coefficients along the labeling function. The actual
point-fiber comparison and its length-one computation identify this with
the fundamental cycle of the scheme-theoretic inverse image:

```text
f^*[i] = ∑_{s : f(s)=i} [s],       (f^*w)_s = w_{f(s)}.
```

`pointFiberMultiplicity` uses the actual fiber's ambient-stalk module
length. `fiberCycle` initially weights its point generators by those
lengths. The length-one theorem and `pullback_pointCycle_eq_fiberCycle`
identify the implemented pullback with this geometric fundamental cycle.

The external product is bilinear extension of the actual point-pair
generator. Intersection is defined by diagonal pullback of that product:

```text
[i] × [j] = [(i,j)],
z · w = Δ^*(z × w),
(z · w)_i = z_i w_i.
```

All four operations descend through the already constructed cycle-to-Chow
isomorphism. Their defining formulas and coefficient formulas are proved
on those actual quotients.

## Correspondence composition

Use the actual product in its proved split presentation:

```text
Corr⁰(Z_I,Z_J) := CH_0(Z_(I×J); ℚ),
κ_JI(c)_(j,i) := c_(i,j).
```

The coordinate equivalence is constructed from the actual Chow quotient.
For `a : Corr⁰(Z_I,Z_J)` and `b : Corr⁰(Z_J,Z_L)`, define

```text
b ∘ a := p13_* (p12^* a · p23^* b).
```

The pullback, intersection, and pushforward coefficient formulas give

```text
(b ∘ a)_(i,l) = ∑_j a_(i,j) b_(j,l),
κ_LI(b ∘ a) = κ_LJ(b) * κ_JI(a).
```

Thus the matrix multiplication is a theorem about the constructed geometric
composition, not the definition of that composition. The diagonal cycle is
the diagonal pushforward of the scheme's fundamental cycle. Its matrix is
the identity. Injectivity of coordinates proves both unit laws and
associativity.

The geometric action on the zero-cycle Chow group is also constructed:

```text
c_* z := p2_* (c · p1^* z),
(c_* z)_j = ∑_i c_(i,j) z_i.
```

It respects correspondence composition and the diagonal identity. This is
an action on the already constructed Chow group.

## Endomorphism algebra and the span quotient

`EndAlgebra K I` keeps the existing Chow addition and scalar multiplication.
Its multiplication is literally `comp`, and its unit is literally
`diagonal`. The proved matrix law gives an algebra equivalence; composition
with the existing exact additive span quotient gives

```text
C_sp^add(Z_I/k) ≃ₐ[ℚ] Γ_I^CH ≃ₐ[ℚ] M_I(ℚ),
κ_II ∘ Ψ_sp = χ̄_sp.
```

The point-span quotient class from input `i` to output `j` maps to the actual
Chow point-pair class `[(i,j)]`. Both have matrix unit `E_ji`. Thus the
equivalence respects the generators, not merely the dimensions of the two
algebras. Multiplication is inherited from the actual Chow construction,
not redefined by transport from matrices.

The comparison also holds for every finite split span, not just the point
generators. `ofSplitSpan` is defined geometrically by pushing the carrier's
fundamental cycle along its pair map. Lean proves

```text
Ψ_sp(overline([S, left, right]))
  = (left,right)_*[Z_S]_0
  = ∑_s [(left(s),right(s))].
```

`spanQuotientEquiv_ofSchemeSpan` proves this equality by comparing the
constructed Chow cycle's incidence matrix with the existing span
realization and using the proved matrix-coordinate injectivity.
